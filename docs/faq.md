# FAQ Help Desk

Документ: `FAQ.md`  
Владелец: Service Desk

## Часто задаваемые вопросы

**Q: Как оформить командировку?**  
A: См. документ `HR-командировки.md`: заявка в Self-Service за 3 рабочих дня.

**Q: Как найти тур / путёвку?**  
A: См. документ `HR-туры.md`: Self-Service → «Путешествия» → «Поиск туров», затем согласование.

**Q: Не работает VPN.**  
A: См. `IT-VPN.md`: проверьте конфиг, DNS, отсутствие второго VPN. Если не помогло — тикет в ITSM.

**Q: Где взять ПО?**  
A: Только из корпоративного каталога (`IT-техника.md`). Установка «с торрентов» запрещена политикой ИБ.

**Q: Как пригласить гостя в офис?**  
A: `ADMIN-пропуска.md` — заявка за 4 часа.

**Q: Вопроса нет в базе?**  
A: Скажите об этом агенту — будет создан тикет в YDB для оператора.
