# Как найти и оформить тур / путёвку

Документ: `HR-туры.md`  
Владелец: HR-отдел / корпоративный тревел

## Кратко

Поиск туров и путёвок для сотрудников — через портал Self-Service → «Путешествия» → «Поиск туров»  
либо через корпоративного тревел-агента. Личные бронирования «мимо» портала на корпоративную карту не компенсируются.

## Шаги поиска

1. Откройте Self-Service → «Путешествия» → «Поиск туров».
2. Укажите: даты, страну/город, тип (отдых / деловая поездка / санаторий).
3. Отметьте фильтры: бюджет, питание, звёздность, трансфер.
4. Сравните 2–3 варианта и сохраните избранное.
5. Нажмите «Запросить согласование» — заявка уходит руководителю и HR.

## Рекомендации

- Бронируйте **не позднее чем за 14 календарных дней** до выезда (горящие туры — за 7 дней, с пометкой «срочно»).
- Для семейных путёвок приложите справку о составе семьи (если требуется льготная программа).
- Страховка включается по умолчанию; отказ только по письменному подтверждению сотрудника.
- Изменения дат после оплаты — через тревел-агента, не через сайт отеля напрямую.

## Что нельзя

- Оплачивать тур личной картой с расчётом на компенсацию без предварительного согласования.
- Бронировать у неаккредитованных агентств вне списка компании.
- Указывать в заявке заведомо неверные даты «для брони».
