# Заказ техники и ПО

Документ: `IT-техника.md`  
Владелец: IT Asset Management

## Что можно заказать

Ноутбук, монитор, гарнитура, лицензии ПО из корпоративного каталога.

## Процедура

1. ITSM → «Оборудование/ПО» → выберите позицию из каталога.
2. Укажите обоснование и согласующего руководителя.
3. После одобрения заявка уходит на склад / закупку.
4. Выдача фиксируется актом; техника — собственность компании.

## Сроки

- Со склада: **2–5 рабочих дней**.
- Закупка: до **20 рабочих дней**.

## Возврат

При увольнении или замене сдайте технику в IT с обнулением данных. Повреждения по вине сотрудника могут удерживаться по акту.
