# Как оформить командировку

Документ: `HR-командировки.md`  
Владелец: HR-отдел

## Кратко

Командировку оформляют **не позднее чем за 3 рабочих дня** до выезда через портал Self-Service → «Командировки».

## Шаги

1. Создайте заявку: даты, город, цель поездки.
2. Приложите приглашение/программу (если есть).
3. Согласование: руководитель → HR → бухгалтерия.
4. После одобрения бронируйте билеты и гостиницу через корпоративного тревел-агента.
5. По возвращении в течение **5 рабочих дней** сдайте авансовый отчёт и чеки.

## Лимиты

- Суточные внутри РФ: по внутреннему регламенту компании.
- Гостиница: эконом/стандарт, бизнес-класс только с отдельным согласованием директора.
