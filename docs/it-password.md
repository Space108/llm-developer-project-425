# Сброс пароля и разблокировка учётки

Документ: `IT-пароль.md`  
Владелец: IT Support

## Сброс пароля самостоятельно

1. На экране входа нажмите «Забыли пароль?».
2. Подтвердите личность кодом из корпоративной почты / SMS.
3. Задайте новый пароль (минимум 12 символов, буквы + цифры + спецвол).

## Если учётка заблокирована

После 5 неудачных попыток учётка блокируется на 30 минут.  
Для срочной разблокировки: ITSM → «Доступ» → «Разблокировка учётки» или звонок на Help Desk.

## Запрещено

- Передавать пароль коллегам.
- Хранить пароль в мессенджерах и открытых заметках.
- Использовать один пароль для работы и личных сервисов.
