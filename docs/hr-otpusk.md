# Отпуск: как подать заявку

Документ: `HR-отпуск.md`  
Владелец: HR-отдел

## Правила

- Ежегодный оплачиваемый отпуск — **28 календарных дней**.
- Заявку подавайте минимум за **14 календарных дней** до начала отпуска.
- Перенос отпуска согласуется с руководителем и HR.

## Как подать

1. Self-Service → «Отпуска» → «Новая заявка».
2. Укажите период и тип отпуска (основной / без сохранения / учебный).
3. Дождитесь согласования руководителя.
4. После статуса «Одобрено» даты фиксируются в табеле.

## Отзыв из отпуска

Возможен только с письменного согласия сотрудника и изданием приказа. Неиспользованные дни предоставляются позже.
